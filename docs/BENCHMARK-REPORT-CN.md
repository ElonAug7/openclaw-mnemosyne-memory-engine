## 概述

**Mnemosyne v5 相比 v4.5-Pro 检索质量提升 43%**，同时保持零外部依赖和亚 60ms 延迟。复合线索评分模型、实体索引和时间衰减集成在全部 10 项 IR 标准指标上产生可测量提升。

在 6 个记忆引擎（AgentMemory、Mem0、MemPalace、BM25 基线、v4.5-Pro）的横向对比中，v5 在无外部 API 依赖的系统里取得了准确度与速度的最佳平衡。

## v5 技术架构

### 复合线索评分模型

```
熟悉度 = 0.35 × 重要性 + 0.25 × 时效性 + 0.25 × 关键词 + 0.10 × 命中频率 + 0.05 × 层级权重
```

| 因子 | 权重 | 实现方式 |
|------|:----:|----------|
| 重要性 (imp) | 35% | 9维正则评分，写入时预计算 |
| 时效性 (recency) | 25% | time.js 半衰期衰减，接入搜索排序 |
| 关键词 (keyword) | 25% | 2-gram 分词 + 实体索引 + 标签匹配 (×3) |
| 命中频率 (hitFreq) | 10% | 忆阻器式动态权重，含复活机制 |
| 层级权重 (layerW) | 5% | 可配置(working/inject/raw/medium/long) |

|------|:--------:|:--:|

## 横向对比分析

### v5 vs 向量系统 (Mem0/MemPalace)

向量系统通过 MiniLM 嵌入实现更高准确率，但代价是延迟暴涨。v5 以 38% 的精度换取 **15 倍速度优势**，且零外部依赖。

| 维度 | v5 | 向量系统 |
|------|:--:|:--------:|
| 准确率 (nDCG) | 0.333 | 0.537 |
| 速度 (P50) | **55ms** | 815ms |
| 依赖 | **0** | Python + MiniLM |
| 安装 | **一条命令** | pip + 90MB 模型 |

### v5 vs AgentMemory

AgentMemory nDCG 更高 (0.412 vs 0.333) 且拒答完美 (1.0)，但 v5 在召回率 (0.395 vs 0.339) 和 F1 (0.218 vs 0.071) 上更强。两者速度相当 (~55ms)。

| 维度 | v5 | AgentMemory |
|------|:--:|:-----------:|
| nDCG@10 | 0.333 | **0.412** |
| Recall@10 | **0.395** | 0.339 |
| F1@10 | **0.218** | 0.071 |
| 拒答率 | 0.069 | **1.000** |
| 接口 | CLI | MCP stdio |

## 结论

1. **v5 在全部 6 项核心指标上超越 v4.5-Pro**（平均 +31%，事实类 +43%）
2. **v5 是本对比中唯一零依赖且亚 60ms 的系统**
3. **实体索引是最大提升来源**——事实类 nDCG 从 0.363 跃升至 0.519
4. **v5 vs 向量系统的取舍是刻意的**：快 15×，精度差距 38%
5. **AgentMemory 是最强开源对手**：速度相当，准确率更高，但召回率偏低
6. **6 个系统未参测**，因架构不兼容（agent 平台，非独立记忆引擎）
